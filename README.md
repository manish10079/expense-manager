# 💰 Expense Tracker — Offline Personal Finance Tracker

Expense Book is a **fast, privacy-focused personal finance tracker** designed for people who want **complete control over their financial data**.

The app runs entirely in the browser and stores all data locally using **IndexedDB**, meaning your financial records stay **on your own device**.

No login required.  
No cloud dependency.  
No tracking.  
No ads.

---

# ❓ Why I Built Expense Book

I used to spend money every day and later ask myself:

*"Where did all my money go?"*

I tried many expense tracker apps, but most of them had problems:

- Required login
- Stored financial data on their servers
- Showed ads
- Locked features behind subscriptions
- Required internet connection
- Felt slow and overly complicated

I wanted something **simple, fast, and private**.

So I built **Expense Book** — a lightweight finance tracker that runs like a desktop app but inside your browser.

It works **offline**, stores data **locally**, and gives users **complete ownership of their financial records**.

# 💡 Design Philosophy

Expense Book follows a **Local-First Software philosophy**.

This means:

- Your data belongs to you
- Apps should work offline
- Users should not depend on a company’s server
- Personal financial data should remain private

---

# 📦 How to Use Offline

You can run the app without internet.

1. Download the `index.html` file
2. Open it in any modern browser
3. Start tracking expenses instantly

All data will be saved locally.
